## 2026-10-09 签名提交与任务新增

真实登录后，进入 Hooks 项目详情，由项目所有者准备签名。后台校验 BSC Testnet、已登记钱包、已独立批准的当前配置及链上 nonce；钱包确认 EIP-712 后提交。API 再验签、重算 MEME 尾号与 Hook 权限位后创建 awaiting_executor 任务。服务端不接收私钥。GET 可查本人任务，DELETE 可取消未执行任务。

数据库保存不可覆盖的签名授权和提交编号；请求超时可用相同提交编号重试。最新任务可更新签名截止时间，原签名记录仍保留。同一链/工厂/钱包/nonce 只允许一个等待任务。取消是本地任务状态变更，不能撤销链上 nonce 或已经公开的有效签名；签名本身仍按工厂的截止时间和 nonce 校验。因此广播组件上线前仍须实现执行前状态重查、幂等领取和回执跟踪。

当前开发服务器没有配置 Privy 凭据、部署后的 Factory 或测试网执行账户；预览模式不连接钱包、不发起签名或链上请求。本轮自动测试使用合成 EIP-712 账户与隔离 PostgreSQL，不能替代真实钱包验收。

本轮验证：API 非数据库集成回归 238 文件 / 3428 用例通过；新增真实 PostgreSQL 任务集成测试 5/5 通过；类型、ESLint、生产构建、格式与 OpenAPI 检查通过。已在浏览器检查项目详情的签名/任务面板，预览模式不触发钱包。开发服务就绪检测为数据库 up，未认证任务请求为 401。
